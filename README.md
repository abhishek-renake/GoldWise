# 🪙 GoldWise – Smart Gold Intelligence Platform

GoldWise is a web-based gold intelligence platform designed to help users monitor gold prices, calculate gold values, track investments, and analyze their gold portfolio through a simple dashboard.

## 🎯 Problem Statement

Gold prices fluctuate frequently, making it difficult for individuals to monitor market prices and understand the value and performance of their gold investments.

GoldWise provides a centralized platform to simplify gold price monitoring and investment tracking.

## 🚀 Key Features

- **Live Gold Prices:** Displays indicative gold prices in INR.
- **Multiple Purities:** Supports 24K, 22K, and 18K gold.
- **Gold Calculator:** Calculates gold value based on weight and purity.
- **Investment Tracker:** Allows users to record and manage gold investments.
- **Profit & Loss Analysis:** Estimates investment performance.
- **Historical Price Chart:** Visualizes gold price trends.
- **Analytics Dashboard:** Displays portfolio distribution and investment insights.
- **Data Persistence:** Stores investment records using browser LocalStorage.

| Technology | Purpose |

| LocalStorage | Investment data storage |
| XAUS API | Gold market price data |

## ⚙️ How It Works

1. The application retrieves indicative gold spot prices through an external API.
2. Prices for 22K and 18K are estimated using gold purity ratios.
3. Users enter gold weight and purity in the calculator.
4. The investment tracker stores purchase details.
5. JavaScript calculates estimated current value and profit or loss.
6. Charts visualize price trends and portfolio analytics.
